# 塔台 · 使用与支持

塔台是一个在 iPhone 本机运行的配置文件转换工具。它把你已有的订阅文本，转换成各个客户端能读的配置文件格式。

**遇到问题、想提需求，或者发现某个订阅解析不对**，请到源码仓库提交 issue：

### → [提交问题](https://github.com/pengchujin/tower/issues)

反馈时请附上：iOS 版本、塔台版本、目标客户端名称，以及客户端报的原文错误信息。**不要贴你的订阅地址或节点链接**——那里面有你的账号凭据。把节点名字和服务器地址打码后的片段就够了。

## 常见问题

### 支持哪些客户端？

Surge、Stash、Clash、Clash Mi、Karing、Shadowrocket、Loon、Quantumult X、Hiddify、sing-box MT、Egern，以及仅接收节点订阅的 V2Box。V2Box 可接收 SS、VMess、VLESS、Trojan、WireGuard、Hysteria 2、SOCKS5 和 HTTP(S)，不会替换它现有的规则和策略组。

### 支持哪些协议？

Shadowsocks、ShadowsocksR、VMess、VLESS、Trojan、Hysteria、Hysteria 2、TUIC、WireGuard、AnyTLS、Snell、SOCKS5、HTTP(S)，共十三种。

### 为什么有节点被跳过了？

因为你选的那个客户端**没有实现**这个协议，或该节点缺少生成可用配置所需的关键字段。比如 Quantumult X 没有 WireGuard，Loon 没有 TUIC，Hiddify 用的内核不含 Snell；WireGuard 多 Peer 配置也不会被有损压成一个节点。

塔台在这种情况下会跳过并计数，而不是把它写成别的协议。写进去的话，配置看着正常，那个节点却永远连不上——这比少一个节点更麻烦。换一个支持该协议的客户端即可。

### 为什么每次导入都多出一条配置？

覆盖、重命名或新增由目标客户端决定，不同客户端的行为不同。不要把塔台的 45 秒本机交接地址当作长期订阅地址。

如果只是希望客户端更新节点，可在高级设置开启“代理集合”，让兼容客户端直接请求原始订阅链接。它不自动更新塔台规则和自有节点，这些变化后仍需重新导出。

### 节点名字显示成 `\U0001F1ED\U0001F1F0` 这样的乱码？

请更新到最新版本。部分服务商的配置文件把中文和旗帜符号写成了转义序列，早期版本没有解码。

### 地区识别不准？

塔台**先看节点自己的名字**判断国家和地区——国旗符号、中英文国名、城市名、国家代码都能识别。名字里看不出来时，才去查随 App 一起打包的离线 IP 数据库。

所以如果某个节点的地区不对，通常是它的名字里带了误导性的词。你可以在节点详情里手动确认。

### 台湾地区的旗帜显示成两个字母？

这是 iOS 系统行为：系统字体里没有该地区的旗帜字形，因此显示为地区代码的两个字母。塔台没有对任何地区做特殊处理，全部交给系统渲染。

### 我的订阅内容会被上传吗？

塔台不会把订阅上传到自己的服务器或第三方在线转换服务，解析和配置生成全部在你的设备上完成。设置中的“代理集合”默认关闭；如果你主动开启，原始订阅链接会写入导出配置，交给你选择的客户端直接更新。详见[隐私政策](privacy.html)。

全部源码公开，上面这些都可以自己去代码里核对：<https://github.com/pengchujin/tower>

### 塔台能替我连接吗？

不能。塔台只负责生成配置文件，它不建立任何网络隧道，也不接管系统流量。实际的连接由你选择的客户端完成。
