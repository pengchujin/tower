# 塔台 1.0.7（45）更新日志

- 改进国家和地区识别，更新离线 IP 数据库，新增离线网络组织信息与手动设置地区。
- 优化大量订阅勾选、刷新和地图缩放性能，减少地区图标闪烁。
- 延迟测试默认自动选择 ICMP / TCP；改为最多 32 个滚动并发，减少慢节点造成的等待，实时显示测试结果。
- 地图按地区成功节点的延迟中位数着色，不可达节点不参与中位数；选中同色加深，优化放大后的选中动画和名称显示。
- 改进规则定制的添加、取消、排序和策略选择，补充手动切换候选，修复规则数量显示不一致。
- 优化表单取消与未保存内容提示，修复部分导入、二维码扫描和导出交互，提升大配置预览性能。
