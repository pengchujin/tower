# 塔台 1.0.32（79）

- 订阅额度：通过在线订阅转换链接（`?target=…&url=<机场订阅>`）添加的订阅，转换服务没有转发额度信息时，改为直接向链接里的机场地址查询剩余流量和到期时间（只读响应头），节点仍以转换链接返回的为准。转换服务返回的 `total=1` 这类占位额度不再显示成「1 字节套餐」。
- 导入 Clash 订阅：读取顶层 `hosts:` 表。机场换入口域名时只改 `hosts`、不改节点 `server`，以前导出的节点全部连不上；现在按 `hosts` 改写节点地址，原域名保留为 SNI / Host，刷新时取消勾选的节点照样保留。
- 导出到 Surge、Loon、Quantumult X：节点名里的 `//` 会被当成注释截断节点行和策略组，现在换成全角斜杠。
- 导出到「Clash」App：支持 Snell v6（App 1.0.18 起内核为 mihomo 1.19.34）；带 HTTP / TLS 混淆或 PSK 长度不合规的 v6 节点跳过并计数。其他 mihomo 客户端仍跳过 v6。
- 局域网共享：v2rayNG、v2rayN、V2Box 扫码或访问链接时自动拿到分享链接列表（Base64），不再返回 400。
- 修复在 Apple 芯片 Mac 上运行 iPhone 版塔台时，关闭窗口后被系统终止（0xdead10cc）的问题：二维码改为自绘，不再经过 Core Image。

支持 iOS 17 及以上；Mac 安装包为 Apple silicon / Intel 通用版本。
