# 1.0.25（64）

## 改进与修复

- 修复 iCloud 同步历史较多时启动闪退的问题。
- 修复恢复备份或同步后，配置名称被设置页旧草稿覆盖的问题。
- 重做使用引导，将添加订阅、分流和导出流程展示得更清楚。
- 整理首页统计与地图、设置分组、筛选条件和导入规则页面。
- 优化添加订阅、剪贴板粘贴和键盘收起操作，修复从管理页返回首页时底部栏跳动。
- 调整 Mac 应用与客户端图标，改善显示效果。
- 更新内置 ACL4SSR 快照。

## Mac 下载

提供 Apple 芯片与 Intel 通用 DMG，最低 macOS 14。分发包已通过 Developer ID 签名和 Apple 公证。

Homebrew 用户可执行：

```sh
brew update
brew upgrade --cask pengchujin/tap/tower
```
