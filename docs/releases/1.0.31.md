# 塔台 1.0.31（73）

- 导出到「Clash」App：严格 DNS 保护改用和其他 mihomo 客户端相同的写法，国外域名经代理解析，选了严格保护也不会再走国内 DNS；策略组带上 3D 图标，名字里不再重复 Emoji。
- 导出到 Egern：支持 ShadowsocksR 节点（Egern 2.21 起）。
- 导出到 Loon：支持 `DOMAIN-WILDCARD` 通配规则（Loon 3.5.3 起），以前被丢掉的通配规则现在会写出来；Reality 节点的指纹改用 Loon 支持的取值。
- 修复导出到 sing-box MT 时，订阅里有 MASQUE 节点会让整份配置加载失败的问题；这类节点改为跳过并提示，等 sing-box MT 支持后再开放。
- 带额外设置的 VLESS XHTTP 节点、非默认模式的 Snell v6 节点无法完整保留，改为导入时跳过并计数，不再导出成连不上的节点。
- Mihomo Party 已改名，客户端列表里显示为 Clash Party。

以下为 1.0.31（72）已包含：

- 修复 iCloud 同步一直提示「iCloud 配置尚未下载完成」的问题：同步历史不再无限增长，缺的文件一次全部下载，已经攒了几百个历史文件的账号会自动清理。

- 内置 ACL4SSR 规则更新到上游最新版本。
