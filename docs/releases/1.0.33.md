# 塔台 1.0.33（80）

- 导出到 Surge / Surge Mac：Surge iOS 6.0 和 Surge Mac 6.12 正式版已经支持 VLESS，现在导出文件、复制配置、一键导入和订阅都直接写入 VLESS 节点，包括 REALITY、XHTTP、gRPC、WebSocket、HTTPUpgrade、Vision 和 VLESS Encryption；VMess、Trojan 的 HTTPUpgrade 和带客户端随机数认证密钥的 TrustTunnel 节点也一并写入。Surge 表达不了的组合（例如不带 TLS 的 gRPC）照旧跳过并计数。
- 以前只有 Surge 测试版能拿到这些节点，导出页会提示「需要 Surge 测试版」；这些提示和「仅 Surge 测试版可用」状态已移除。
- 注意：Surge iOS 5.x 和 Surge Mac 6.11 及更早版本不认识这些节点，订阅里有它们时整份配置会加载失败，请先把 Surge 升级到最新版。
- 内置 ACL4SSR 规则更新到上游 `a77a123`（规则内容与上一版相同）。

支持 iOS 17 及以上；Mac 安装包为 Apple silicon / Intel 通用版本。
