# 塔台 1.0.6 (41)

- 新增 Clash Mi、Karing 配置导出支持。
- 新增客户端筛选与排序，局域网共享入口也可一起显示、隐藏和排序。
- 优化客户端选择：点击后保持位置，边缘卡片平滑滚动至完整可见，不再强制居中。
- 新增默认关闭的「代理集合」，支持的客户端可通过原始订阅链接自行更新远端节点；自有节点仍本地生成。
- 修复订阅刷新与编辑、iCloud 同步并发时可能覆盖新数据的问题。
- 修复地图展示与节点分享可能使用旧内容的问题，优化配置缓存与客户端切换效率。
- 改善拖动排序、连续操作、大字号及无障碍体验。
- 更新内置 ACL4SSR 规则快照及配套 MRS/SRS 规则集。

代理集合仅适用于兼容客户端，远端节点不受塔台逐节点勾选和协议筛选控制。塔台规则或自有节点变化后仍需重新导出。
